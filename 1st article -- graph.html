Get Started

Start by cloning this repo and running its setup script. 

git clone https://github.com/dcsw/my-nemoclaw-setup
cd my-nemoclaw-setup
./setup.sh

BAM! Just like that, you have a nemoclaw sandbox up and running with openshell protecting it.

Its name is my-deepagents. See below for how to use other names. 

nemoclaw list

Connect to your new Sandbox

We can now get to work with DeepAgents by just connecting to our new sandbox.

Give it your NVIDIA API key by environment variable and you’re off! 

export NVIDIA_INFERENCE_API_KEY=[your key goes here]
nemoclaw my-deepagents connect

You’re in, Start dcode and Start to Code!

Once you’re in the sandbox, make a subfolder and start the DeepAgents cli, dcode.

Use the auto-approve flag, and don’t worry. It doesn’t automatically go into auto-approve mode. It just enables it. 

mkdir example
cd example
dcode -y

On to the good stuff!

Here comes the good stuff — multi-subagent agentic vibe development!

Trigger DeepAgents with the keyword “workflow” or use dcode’s “/goal” command.

We’ll demo vibing a stock graph in a next article. Here’s a preview where we run the following /goal command. 

/goal Make me a github action that fetches AAPL's stock history.
Then make an html page that graphs it.

When you do, dcode will work for a bit, and then trigger a set of HITL (Human In The Loop) approvals asking for proposal criteria acceptance.

Accept them all with abandon. Remember, you’re safely sandboxed.
